## 環境変数ファイル（.env）の設定

このプロジェクトでは、環境変数を `.env` ファイルから読み込む構成になっています。

まず、リポジトリに含まれている `.env.example` を `.env` にコピーしてください。

```bash
cp .env.example .env
```

コピーした `.env` ファイルは、**開発環境や本番環境に応じて必要な値を変更**してください。

以下の項目は、本番環境での接続に合わせて変更する必要があります。

```ini
DB_USER=本番用のユーザー名
DB_PASSWORD=本番用のパスワード
```

それ以外の項目は、通常変更不要です。

`.env` の値はアプリケーション起動時に読み込まれ、`process.env.XXX` として利用されます。
したがって、`docker-compose up` や `npm run start:dev` を実行すれば、自動的に `.env` の設定が反映されます。

この方式により、開発者や本番環境ごとに異なる設定を安全に管理することができます。
